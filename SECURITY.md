# Security Policy

## Supported versions

Only the latest version on the App Store and Google Play receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems. Report privately via
**Security → Report a vulnerability** in this repository, or email
berkecan.koc.contact@gmail.com.

Include the app version and platform, steps to reproduce, and the impact you observed.
You can expect a first reply within 7 days.

## Scope

Patilog has no servers or accounts; all data stays on the device. Relevant reports
include exposure of locally stored records or photos to other apps, notification or
link handling that opens or changes the wrong pet's records, and secrets or signing
material in this repository.
